# HNG — Stage 0: Testable Profile Card

Welcome to my Stage 0 task submission for the **Frontend Wizards Program** 🎉  
This project is a responsive, accessible **Profile Card component** built with **semantic HTML**, **modern CSS**, and **vanilla JavaScript**.  
Each profile card displays user information, hobbies, dislikes, and live time in milliseconds, with all required `data-testid` attributes for automated testing.


 Features

✅ Semantic HTML5 structure (`article`, `section`, `figure`, `nav`, etc.)  
✅ Accessible and keyboard-friendly layout  
✅ Responsive design for mobile, tablet, and desktop  
✅ Real-time clock showing `Date.now()` in milliseconds  
✅ Social links open safely in a new tab (`target="_blank"` + `rel="noopener noreferrer"`)  
✅ All elements include the required `data-testid` attributes
